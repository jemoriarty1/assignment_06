I learned how to call a REST API Each function in apicalls.py sends my API key to one endpoint and calls raise_for_status(). A bad HTTP status code such as 401 or 404 immediately triggers an error. I struggled when my tests failed with a RuntimeError because I had not set my API key in .env. Next I will call one endpoint with a key, a wrong key and a misspelled path and I will note the HTTP status code that raise_for_status() reports, for each.
