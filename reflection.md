One concept I learned is the difference between extract and transform steps in a pipeline: sentiment_step calls the Azure sentiment API once per review and caches the raw JSON to a file, while sentences_table uses pd.json_normalize with record_path="sentences" and meta=["review_id"] to flatten that JSON from one row per review to one row per sentence, changing the grain without touching the network. A difficulty I ran into was in summarize_items, where I counted positive and negative mentions with groupby and agg, but the test required pd.pivot_table, and I first put the index columns in the wrong order, so subject and item came out reversed. I did not fully understand that a pivot table with columns="mention_sentiment" turns each sentiment value into its own column, which is why I needed reindex(..., fill_value=0) when a filtered selection had no negative mentions. My next step is to build a small DataFrame of ten mentions by hand, run pd.pivot_table on it with different index, columns, aggfunc and fill_value settings, and predict each output before running it until my predictions match.
