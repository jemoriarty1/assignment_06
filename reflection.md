I learned how to call a REST API safely: each function in apicalls.py sends my API key to one endpoint and calls raise_for_status(), so a bad HTTP status code like 401 or 404 raises an error immediately. I struggled when my tests failed with a RuntimeError because I hadn’t set my API key in .env. Next, I will call one endpoint with a correct key, a wrong key, and a misspelled path, and record the HTTP status code raise_for_status() reports for each.
